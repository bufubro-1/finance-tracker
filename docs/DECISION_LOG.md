The status column identifies the remaining boundaries explicitly.

| ID | Proposal | Status | Rationale, alternatives, and affected work |
|---|---|---|---|
| DEC-009 | Modular Python monolith; Streamlit, SQLite, Pandas/Plotly; replaceable API adapters; optional host-scheduled local command. | Proposed; Charter-aligned | Keeps deployment small and avoids rerun-triggered duplicate schedulers. | DEC-011 | Restate history using effective dated postings and corrected manual prices; no original-as-known snapshots in v1. | Proposed | Historical corrections may change old charts; preserve observation/transaction audit trails and label restated reports.
